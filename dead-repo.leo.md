# Leo

Yes — the GitHub repo (and NotRexed's entire GitHub account) was **taken down on November 13, 2026**. NotRexed stated on Discord that his account was "nuked," with no official DMCA notice found in GitHub's archive.

The project itself is **not dead**. It has moved to NotRexed's self-hosted server:

- **Hookshot** (original, by NotRexed): [git.notrexed.dev/Hookshot/Hookshot](https://git.notrexed.dev/Hookshot/Hookshot)
- **Longshot** (fork by most of the active dev team, citing governance disputes): [git.magicbean.dev/MagicBeanDev/Longshot](https://git.magicbean.dev/MagicBeanDev/Longshot) — already at v3.0.0-rc.3, with a new launcher, faster builds, and improved shader compilation.

An archived mirror of the original GitHub repo also exists at `git.magicbean.dev/MagicBeanDev/Hookshot` for history.

If you had Hookshot installed before the move, your builder is still checking the old GitHub URL for updates. A community tool called [hookshot-relink](https://github.com/1sythe/hookshot-relink) can point it to the new server.
